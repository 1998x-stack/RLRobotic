# RLRobotic

> 机器人强化学习研究笔记与路径规划（RL path planning）资料合集。

## 📌 项目概述

`RLRobotic` 是一个**机器人强化学习**领域的资料与研究项目，核心由 `RLPathPlanning` 子模块构成，汇集了四足 / 双足机器人运动控制的经典论文笔记，涵盖**感知运动（perceptive locomotion）**、**分层强化学习步态生成**、以及**鲁棒参数化运动控制**等方向。

## 📚 主要内容

- `RLPathPlanning/` — RL 路径规划子模块
- `doc.md` — 论文阅读笔记，收录包括：
  - **PRELUDE**：Learning to Walk by Steering（感知四足运动，分层学习）
  - **HRL 多步态**：四足机器人分层强化学习步态控制
  - **Robust Parameterized Locomotion**：双足机器人 Cassie 鲁棒运动控制

每篇笔记均给出摘要与 arXiv / 项目链接，便于他人查找原文跟进。

## 🎯 用途

- 机器人 RL 入门 / 进阶学习
- 四足、双足步态控制与感知运动研究资料索引
